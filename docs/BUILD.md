# بناء مكتبتي

## المتطلبات
- Java 17.
- Gradle 8.7 (مثبت محليًا؛ لا يتضمن المستودع Gradle Wrapper).
- Android SDK Platform 35 وBuild Tools 35.0.0.
- Android TV 9 هو بيئة التطبيق المستهدفة؛ توافق الإصدارات الأحدث يحتاج اختبارًا.

اضبط ANDROID_HOME إلى مسار SDK الخاص بك، أو أنشئ android/local.properties محليًا يتضمن sdk.dir. لا ترفعه إلى Git.

من جذر المستودع:

```sh
gradle -p android --no-daemon :app:testDebugUnitTest :app:assembleDebug
```

النتيجة: android/app/build/outputs/apk/debug/app-debug.apk.

تستخدم نسخة Debug مفتاح التطوير الذي يولده Android SDK محليًا. لا تحتاج أي مفتاح لصاحب المشروع. لا توجد مفاتيح مرفقة، ولا ينبغي نشر المفتاح المحلي. احتفظ بمفتاحك عند توزيع تحديثاتك الخاصة.

## التشغيل
ثبّت النسخة المبنية على جهاز اختبار Android TV. اسم الحزمة org.maktabati.tv، مستقل عن النسخة الشخصية، ولن يستبدلها. افتح التطبيق وامنحه إذن قراءة التخزين عند الحاجة، ثم افحص USB. استخدم VLC للتشغيل والاستكمال.

من «إعدادات معلومات الأفلام» أدخل TMDb API Read Access Token الخاص بحسابك. هذا اختياري، ويُحفظ مشفرًا بمفتاح Android Keystore محلي. لا تضعه في الكود أو ملفات Git أو Issues.

لا يضيف المشروع HOME ولا يعدّل نظام TCL. لا يتضمن خادم نقل أو بوابة تحكم من الهاتف.

## الاختبارات
اختبارات الوحدة تغطي البحث والمطابقة والحذف ونصوص الأخطاء والترجمات ومسارات VLC. نجاح البناء لا يعادل اختبار جميع أجهزة التلفزيون والأقراص.
