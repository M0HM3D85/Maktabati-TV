# اتجاهات التطوير المقترحة

هذه أفكار قيد الدراسة، وليست ميزات مكتملة أو مواعيد تسليم:

- تحسين مطابقة أسماء الملفات ببيانات TMDb وإدارة الحالات غير المؤكدة.
- توسيع تغطية الوصف العربي مع توضيح مصدره.
- اختبار مزيد من أجهزة Android TV وأنواع الأقراص.
- تحسين عرض تقدم النقل وأخطاء التخزين للمستخدم.
- فصل التكاملات الخاصة قبل تقييم إصدار عام مستقل.
- مراجعة تراخيص الكود والأصول وتوثيق البناء قبل إتاحة المصدر.
