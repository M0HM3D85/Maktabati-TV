# النسخة العامة المستقلة

نُقل المصدر المنتقى فقط إلى هذا المستودع، دون تاريخ المستودع الشخصي.

- حزمة مستقلة org.maktabati.tv، دون إعدادات توقيع المالك.
- استبعاد جسر تطبيق التحكم الخاص MetadataPhoneProvider وأداة فحص الكتابة الخاصة به.
- ملف arabic-overviews.json فارغ بدل قائمة ملخصات المكتبة الشخصية.
- لا نسخ احتياطية أو تفضيلات أو قواعد بيانات أو فهارس أو رموز وصول أو مفاتيح توقيع.
- لا APK أو تقارير جهاز أو ملفات فيديو أو ملفات إعداد محلي.
- مسح USB الكامل دون اعتماد على اسم مجلد سنة محددة.
- NetworkFiles آلية ملفات داخلية وليست خادم شبكة أو واجهة جاهزة. بناء واجهة عامة لها يحتاج مصادقة وحدود استخدام.
- الاختبارات تستخدم أسماء وبيانات تجريبية ثابتة؛ كلمة SECRET في اختبار تنقية الأخطاء قيمة وهمية وليست رمزًا.
- صور المعرض سابقة وتصف تجربة النسخة الشخصية؛ النقل من المتصفح والملخصات الخاصة لا يأتيان مع المصدر العام.

لم تُغيّر النسخة المثبتة على تلفزيون صاحب المشروع.
